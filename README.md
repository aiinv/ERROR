# ERROR

从 Chrome 断网错误页（`ERR_CONNECTION_TIMED_OUT` / `ERR_INTERNET_DISCONNECTED`）中提取并修复的**恐龙快跑**小游戏，界面与断网页面一致，直接打开即可玩。

## 在线玩

https://aiinv.github.io/ERROR/


## 玩法

- 空格 / ↑ / 点击屏幕：起跳
- ↓：下蹲
- 撞到障碍物后按空格重新开始
- 计分与最高分（保存在本地）

## 说明

- 纯单文件页面，无外部依赖，内联全部精灵图资源，离线也能玩。
- 已从原始错误页中修复音频断言导致的“按空格无法开始”问题。
- 适配桌面与手机竖屏，界面复刻标准 Chrome 断网页面。
